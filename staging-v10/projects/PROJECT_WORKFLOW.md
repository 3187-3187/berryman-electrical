# Berryman Electrical — Recent Work / Proof Workflow

## Purpose
Turn genuine completed jobs into compact proof pages that help customers, local SEO and AI/search understanding without exposing customer privacy or inventing claims.

## Minimum information for a project
1. Suburb/locality (not exact residential address)
2. Customer-visible problem or job request
3. What was diagnosed / found
4. What work was completed
5. Practical outcome after testing/completion
6. 1–5 genuine approved photos
7. One primary service page to link to
8. One relevant area page when appropriate

## Photo rules
- Real Berryman Electrical work only
- Remove/avoid faces unless permission exists
- Remove number plates, house numbers, paperwork, access codes and private information
- Avoid showing unsafe temporary conditions without explaining context
- Compress images for web while retaining enough detail to prove the work
- Use descriptive alt text that says what is actually visible

## Publishing rule
The Projects hub and template remain NOINDEX until genuine projects are loaded. Recommended launch threshold: at least 3 strong genuine projects, preferably across more than one service and more than one locality.

## Project-page SEO / AI structure
- Human-readable H1 based on the actual outcome + suburb
- Short direct summary near the top
- Clear Problem / Diagnosis / Work completed / Outcome fields
- Related service + related area links
- Article/CreativeWork structured data only after the page contains real content
- Never use AggregateRating for self-serving review markup
- No invented dates, customer quotes, prices or performance claims

## Ongoing operating workflow
After a worthwhile job: take 2–5 useful photos → record suburb/problem/diagnosis/work/outcome → privacy check → create project draft → quick factual review → publish → add to homepage Recent Work and related service/area page.
